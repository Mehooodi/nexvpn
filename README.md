# NEXVIA Android — Starter

این نسخه، اسکلت اولیه اپ NEXVIA است:
- صفحه ورود کد/رمز
- داشبورد
- دکمه اتصال نمایشی (فعلاً VPN واقعی وصل نمی‌کند)
- برند NEXVIA
- Designed by Mehooodi

## اجرا
1. Android Studio را نصب کن.
2. این پوشه را Open کن.
3. اجازه بده Gradle dependencies را دریافت کند.
4. یک Android Emulator یا گوشی واقعی انتخاب کن.
5. Run را بزن.

## مرحله بعد
بعد از آماده شدن VPS، بخش اتصال واقعی WireGuard/VPN و API احراز هویت به همین پروژه اضافه می‌شود.
